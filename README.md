# Resto Чаты — сборки

Сюда автоматически выкладываются обновления приложения Resto Чаты. Исходников тут нет.

**Установить:** скачайте [RestoChats-Setup.exe](https://github.com/danilagafonov939-art/resto-chats-releases/raw/main/RestoChats-Setup.exe) и запустите. Дальше приложение обновляется само.

- `latest.json` — какая версия сейчас актуальна (приложение проверяет его при запуске и раз в 2 часа)
- `app-*.asar` — начинка приложения, которую оно скачивает при обновлении
